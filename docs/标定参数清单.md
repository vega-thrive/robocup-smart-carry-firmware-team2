# 标定参数清单（全工程）

> **铁律：所有距离常量基于实测标定 1850 counts/cm，非理论值（理论约 2315 counts/cm =
> 77mm 轮径 + 500PPR×4 倍频×1:28 减速比）。麦轮打滑、轮子形变、地面摩擦、编码器安装误差
> 造成差异。改动任何常量前必须实车重标定，切勿按理论值换算。**
>
> 本清单汇总当前工作区全部标定参数与位置，快递到货后请逐项复核（见 §9 复检清单）。

## 9. 快递到货后复检清单（建议按此顺序）

1. **电源与电机方向**：上电 SERVO_TEST_MODE 单测 CH2 转盘（500→2500 步进），确认舵机行程与 840/2440 档位；
2. **编码器**：`TASK1_CIRCLE_TEST_MODE` 前先手推车看 VOFA `velocity[1..4]` 方向/数值，确认四轮一致；
3. **陀螺仪**：HWT101 就绪（`Angle` 稳定、帧龄 <200 ms），左转 90° 验证 `yaw_ccw_sign`；
4. **距离复核**：按 §2 抽查 3~5 个关键位移（84 cm、11 cm、34 cm、222 cm），记录实测 counts/cm 偏差；
5. **视觉**：MaixCAM 对准 (208,160)，验证 X/Y 方向符号与进入带；
6. **转盘槽位**：5 档 PWM 逐一验证物块/奖杯对位；
7. **全流程**：跑一次完整比赛，对照状态机文档 §3 检查每个状态转移与 LCD 显示一致；
8. **调参**：用 VofaTune 在线复核 §4 各增益是否仍合适，把最终值回写本文档。

## 10. 修改纪律

- 任何标定量改动 → 更新本文档对应条目（值 + 日期 + 实测依据）；
- 行为保持的重构（抽常量、删死代码）→ 改前打 tag，改后跑一次完整流程确认；
- 禁止：按理论值换算距离、改 TIM7 周期、改电机/编码器极性、删"看似多余"的转移条件。
