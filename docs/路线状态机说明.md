# 路线状态机说明（ProjectService.c）

> 本文档基于当前工作区代码逐行核对，描述 **ProjectService.c**（2821 行）中全部路线状态、
> 转移条件与子状态机。**修改任何状态转移条件前请先读本文档**；凡标注"活跃"的路径均为
> 实车跑通路径，改动需谨慎。标注"遗留/不可达"的为当前流程未触发的代码，可安全整理。

---

## 1. 运行框架

| 执行上下文 | 频率 | 内容 |
|---|---|---|
| 主循环 `CompetitionTask_Process()` | ~100 Hz（`HAL_Delay(10)`） | `CompetitionQr_Process()`、`VisionAlignment_Process()`、`ProjectService_Run()`（状态显示、非实时逻辑：PLACE_PREPARE / VISION_ALIGN / VISION_FORWARD / PLACE / VISION_BACK / PLACE_ERROR 等） |
| TIM7 中断 `ProjectService_OnTimerElapsed()` | 200 Hz（5 ms，PSC=840-1, ARR=500-1） | `ChassisMotor_SampleEncoders()` → `ChassisMotor_IntegrateEncoders()` → 全部运动状态机 → `ChassisMotor_ControlTick(wheel_target)` 输出四轮 |
| TIM9 中断（最高优先级 0） | 软件 PWM，20 ms 帧 | 8 路舵机脉宽生成（`Servo4_TIM9_IRQHandler`） |
| 串口 | — | UART4=MaixCAM 视觉(115200)、UART5=HWT101 陀螺仪(115200)、USART1=GM65 扫码(9600)、USART2=VOFA 调参(115200) |

关键约定：
- **运动状态机几乎全部在 TIM7 ISR 内执行**（`ProjectService_OnTimerElapsed`），主循环只做显示与少量逻辑。
- 每 5 ms 先采样编码器速度 `velocity[1..4]`（计数值/5ms），再积分到 `encoder[1..4]`。
- 所有轮速目标经 `LineFollow_SetWheelTargets(wheel_target[5])` 原子发布，ISR 末尾统一 `ChassisMotor_ControlTick` 消费（四轮增量式速度 PID → `Move_Control` 输出 PWM）。

## 4. 状态详解（活跃路径，按执行顺序）

> 说明：除注明"主循环"外，均在 TIM7 ISR（200 Hz）中执行。`ChassisPos_Update(max_fwd, max_left, hc)`
> 为梯形位置环：返回 1 表示"到达+速度收敛+航向稳定（连续 15 ticks）"。所有距离单位 = 编码器计数（1850 counts/cm）。

### 4.1 ROUTE_HOME_LAUNCH（出库）
- **入口**：上电初始态（`ProjectService_Init` 后）。
- **动作**：`home_launch_tick=0` → `ChassisPos_Start(120000×4)`（约 65 cm）；`tick=1` 时 `ChassisPos_Update(HOME_LAUNCH_SPEED=300)`；完成后记录 `home_turn_start_absolute`，`tick=2`。
- **转弯**：按 `|Angle|` 左转（方向码 `-spd,-spd,spd,spd`），>70° 开始线性减速（斜率 13.2，下限 120）。
- **出口**：`|Angle| >= 90°` → 记录 `left_heading_absolute`、`yaw_ccw_sign`（按实际转向方向）→ **ROUTE_HOME_FIXED_FORWARD**（`ChassisPos_Start(155400×4)`）。
- 备注：`HOME_LAUNCH_FWD_TICKS=400` 仅用于 LCD 显示，实际前进是编码器 120000 counts 定位。

### 4.2 ROUTE_HOME_FIXED_FORWARD（前进 84 cm）
- `ChassisPos_Update(HOME_FIXED_FORWARD_SPEED=400, 0, 航向修正)` 完成 → **ROUTE_HOME_FIXED_PAUSE**，并发起 `CompetitionQr_RequestStart(COMP_QR_TASK1)`。

### 4.3 ROUTE_HOME_FIXED_PAUSE（扫描任务1 QR）
- 停车等待：`home_fixed_ticks >= 100`（500 ms）**且** QR 状态为 READY 或 DEFAULTED → 后退启动（`ChassisPos_Start(-70300×4)`，3.8 cm）→ **ROUTE_HOME_FIXED_LEFT**。
- QR 未就绪时一直等待（LCD 显示扫描状态/尝试次数）。

### 4.4 ROUTE_HOME_FIXED_LEFT（后退 + 左移，灰度十字提前退出）
- phase 0：`ChassisPos_Update(240, 0)` 后退完成 → phase 1，左移 `ChassisPos_Start(-77700, 77700, -77700, 77700)`（4.2 cm）。
- phase 1：`ChassisPos_Update(0, 290)` 完成，**或**前八路灰度 `GS4&&GS5` 且总数==2 连续 3 ticks（十字检测）→ **ROUTE_HOME_FIXED_SETTLE**。

### 4.5 ROUTE_HOME_FIXED_SETTLE
- 停 30 ticks（150 ms）→ 复位巡线 PID、`TurntableInventory_Reset()`、`Task1Color_Start()`（切摄像头 COLOR 模式）、`LineFollow_LatchSpeeds()` → **ROUTE_TRACK_FIRST**。

### 4.6 ROUTE_TRACK_FIRST（任务1 巡线收块）
- **巡线**：八路灰度加权位置 `line_state = Σ weights[i]`（权重 -12..12）→ 位置式 PID（kp=9.0, ki=0.15, kd=0.8，I 限幅 200，输出限幅 450）→ 左右列差速。全黑（black_count==0）保持上次转向。
- **收块**：`Task1Color_Process()`（主循环）从 MaixCAM 收 5 种颜色码（21~25）→ `TurntableInventory_RecordColor` → `Servo4_RotationSetStep(count)` 转盘逐槽前进。
- **出口**：`Task1Color_GetCount() >= 5 && GS1..4 全黑` → `Servo4_Task1RotationLockNow()`（PWM-200 锁死转盘）→ 停 100 ticks → **ROUTE_ROTATE_90**。

### 4.7 ROUTE_ROTATE_90（右转 90°）
- 方向码 `spd,spd,-spd,-spd`，>70° 减速（斜率 7.5，下限 80）。
- `|Angle| >= 90°` → 复位 → **ROUTE_CURVE**：`ChassisPos_Start(77700+22200, 77700-22200, 77700+22200, 77700-22200)`（前 42 cm 同时右 12 cm，真斜向）。

### 4.8 ROUTE_CURVE（斜向前进）
- `ChassisPos_Update(CURVE_FORWARD_SPEED=180, CURVE_RIGHT_MOVE_SPEED=130, 航向修正)` 完成 → 设置 `vision_next_mode=ROUTE_REAR_ALIGN`、`pause_next_mode=ROUTE_PLACE_PREPARE` → **ROUTE_PAUSE_GENERIC**。
- 备注：`cross_marker` 灰度十字判定已被注释（`/* || cross_marker_ticks >= 3 */`），当前纯编码器定位。

### 4.9 ROUTE_PAUSE_GENERIC（通用暂停，双用途）
- 计数 `mode_entry_tick`；`>= PAUSE_GENERIC_TICKS(100)` 且（非"等任务2 QR"场景）→ 按 `pause_next_mode` 转跳：
  - `ROUTE_FINAL_ROTATE_30`：仅复位编码器（旋转本身在 FINAL_ROTATE_30 内做）。
  - `ROUTE_FINAL_FORWARD_2`：`ChassisPos_Start(61050×4)`（33 cm）。
  - `ROUTE_FINAL_ROTATE_ALIGN`：复位对准状态。
  - `ROUTE_FINAL_LEFT_40`：stage 0 → `ChassisPos_Start(-203500, 203500, ...)`（11 cm）；stage 1（死代码）→ 2 cm 且**等任务2 QR**。
  - `ROUTE_PLACE_PREPARE`：直接续行放置流程。
  - `ROUTE_VISION_ALIGN`：直接进视觉对准。
- 等 QR 场景：`pause_next_mode==ROUTE_FINAL_LEFT_40 && final_left_stage==1` 时需 QR READY/DEFAULTED 才放行——**但 final_left_stage 永不为 1，该分支不可达**（见 §7）。

### 4.10 ROUTE_PLACE_PREPARE（主循环，放置准备）
- 色块（`vision_job==VISION_JOB_COLOR_PLACE`）：`place_seq_index < 5`，由 `CompetitionQr_GetTask1PlaceColor(任务码, index)` 得到目标颜色 → `TurntableInventory_FindColor` 查槽位。
- 奖杯（遗留分支）：`task2_place_index < 3`，QR 映射目标奖杯 → `FindTrophyRank`。
- **出口**：找到 → **ROUTE_VISION_ALIGN**；找不到 → **ROUTE_PLACE_ERROR**；全部放完（色块 5 个/奖杯 3 个）→ `route_state = vision_next_mode`（续行）。

### 4.11 ROUTE_VISION_ALIGN（主循环 + ISR，视觉对准）
- `vision_skip` 非 0：跳过视觉，按 `vision_next_mode` 预置位移（REAR_ALIGN→左 2.5 cm / REAR_ALIGN_2→后 40 cm / FINAL_LEFT_FORWARD→后 20 cm）后直接转跳。
- 正常：`VisionAlignment_Start(VISION_PROFILE_TASK1)`（主循环发起），ISR 每 tick 把 `VisionAlignment_GetWheelTargets` 写入 `wheel_target`。
- **VISION_ALIGN_DONE**：圆测模式→MISSION_DONE；正常→`ChassisPos_Start(4070×4)`（2.2 cm）→ **ROUTE_VISION_FORWARD**。
- **VISION_ALIGN_TIMEOUT**：圆测模式→MISSION_DONE；色块任务→**ROUTE_PAUSE_GENERIC**（跳过一个放置点继续）；奖杯任务→**按 DONE 处理继续前插**（即超时视为"够了"，属遗留路径）。

### 4.12 ROUTE_VISION_FORWARD（直进 2.2 cm）
- `ChassisPos_Update(VISION_FORWARD_SPEED=250)` 完成 → **ROUTE_PLACE**（place_step=0）。

### 4.13 ROUTE_PLACE（物块释放，主循环）
- step 0：`Servo4_RotationUnlockTo(place_pwm_us)` 转盘转到目标槽，按脉宽差估算等待 ticks。
- step 1：等待到位；
  - 色块且 `place_seq_index==4`（第 5 块）：→ step 2（大臂收拢到 Task0 姿态）；
  - 色块（前 4 块）：→ step 4（物块落稳 400 ms）；
  - 奖杯（遗留）：后退 2.7 cm（ROTATE_30 场景多退 3 cm）→ **ROUTE_VISION_BACK**。
- step 2：`Servo4_ArmRampTick(Task0)` 完成 → step 4。
- step 4：停 `TASK1_BLOCK_DROP_SETTLE_TICKS=40` ticks → 后退 1 cm（`ChassisPos_Start(-1850×4)`，`task1_back_phase=1`）→ **ROUTE_VISION_BACK**。
- 备注：**CH2 转盘在物块落稳期间不旋转不锁止**（防震动干扰）。

### 4.14 ROUTE_VISION_BACK（放置后退出，主循环）
- 色块两段式：phase1 蠕动 1 cm（`TASK1_BACK_CLEAR_SPEED=100`）→ 剩余距离（总 `TASK1_PLACE_BACK_DISTANCE=8695`，4.7 cm；ROTATE_30 场景 +3 cm）以 `VISION_FORWARD_SPEED` 快速退完 → `TurntableInventory_MarkEmpty`、`place_seq_index++`、`Servo4_Task1RotationLockNow()`。
- 奖杯（遗留）：`MarkEmpty`、`task2_place_index++`；放满 3 个 → **ROUTE_HOME_RETURN_ALIGN**；否则 → **ROUTE_PLACE_PREPARE**。
- **色块续行**（按 `vision_next_mode`）：REAR_ALIGN→预置左 2.5 cm；REAR_ALIGN_2→预置后 40 cm；FINAL_LEFT_FORWARD→预置后 20 cm；其余→直接转跳。

### 4.15 ROUTE_REAR_ALIGN（后对准1）
- phase 0：`ChassisPos_Update(0, 240)` 左移 2.5 cm → phase 1：`ChassisPos_Start(55500×4)`（30 cm）。
- phase 1：`ChassisPos_Update(380)` 完成 → **ROUTE_PAUSE**。

### 4.16 ROUTE_PAUSE / ROUTE_PAUSE_2
- 停 50 ticks（250 ms）/ 100 ticks（500 ms）→ 设 `vision_next_mode`（REAR_ALIGN_2 / FINAL_LEFT_FORWARD）→ **ROUTE_PLACE_PREPARE**。

### 4.17 ROUTE_REAR_ALIGN_2（后对准2）
- phase 0：`ChassisPos_Update(120)` 后退 30 cm → phase 1：`ChassisPos_Start(-157250, 157250, -157250, 157250)`（左移 8.5 cm）。
- phase 1：`ChassisPos_Update(0, 320)` 完成 → **ROUTE_PAUSE_2**（十字提前退出已注释）。

### 4.18 ROUTE_FINAL_LEFT_FORWARD（左前组合位移）
- phase 0：前进 30 cm（180）→ phase 1：左移（`lat = 55500*340/180*2 - 74000 ≈ 135666`，约 7.3 cm）→ phase 2：`ChassisPos_Start(92500×4)`（50 cm）。
- 完成 → 设 `vision_next_mode=ROUTE_FINAL_ROTATE_30`、`pause_next_mode=ROUTE_PLACE_PREPARE` → **ROUTE_PAUSE_GENERIC**。

### 4.19 ROUTE_FINAL_ROTATE_30（右转 35°）
- `|Angle| >= 35°` → **ROUTE_PAUSE_GENERIC**（pause_next_mode=ROUTE_FINAL_FORWARD_2）。

### 4.20 ROUTE_FINAL_FORWARD_2（前进 33 cm）
- `ChassisPos_Update(320)` 完成 → 设 `vision_next_mode=ROUTE_FINAL_ROTATE_ALIGN`、`pause_next_mode=ROUTE_PLACE_PREPARE` → **ROUTE_PAUSE_GENERIC**。

### 4.21 ROUTE_FINAL_ROTATE_ALIGN（大臂收拢 + 航向精对准）
- 先 `Servo4_ArmRampTick(Task0 姿态)` 收拢大臂（防撞已放物块）。
- 粗转：`|Angle|` 到 38.4°（48°×0.8）前按 280 转（>28.8° 减速斜率 10，下限 100）。
- 精对准：对 `left_heading_absolute`（Home 左转 90° 后记录的绝对航向）误差 ≤2° 连续 3 帧（或 200 ticks 超时）→ 设 `pause_next_mode=ROUTE_FINAL_LEFT_40` → **ROUTE_PAUSE_GENERIC**。

### 4.22 ROUTE_FINAL_LEFT_40（左移 11 cm）
- `ChassisPos_Update(0, 320)` 完成 → **ROUTE_TASK1_TO_TASK2**（task2_transition_step=0）。

### 4.23 ROUTE_TASK1_TO_TASK2（任务1→任务2 过渡，子步骤 0~8）
| step | 动作 |
|---|---|
| 0 | 停 `Task1Color_Stop()`、摄像头 STOP、复位、发起任务2 QR 扫描 |
| 1 | 等 QR READY/DEFAULTED；超时 800 ticks（4 s）→ `CompetitionQr_ForceDefault` |
| 2 | `TurntableInventory_Init(840,400)`、`Servo4_RotationHome()`、`TrophyLittleAllOpen()`、清零收集计数 |
| 3 | 大臂缓降到工作姿态（`ArmRampTickSlow`） |
| 4 | 左移 2 cm：`ChassisPos_Start(-37000, 37000, -37000, 37000)` |
| 5 | `ChassisPos_Update(0, 320)` 完成 |
| 6 | 原地转 179°（`FINAL_ROTATE_180_SPEED=372`） |
| 7 | 停 40 ticks（200 ms） |
| 8 | 复位、摄像头切 TROPHY_WHITE 模式 → **ROUTE_TRACK_RETURN** |

### 4.24 ROUTE_TRACK_RETURN（任务2 反向巡线收杯）
- 巡线同 TRACK_FIRST，速度 `linefollow_task2_speed_active`（默认 230）。
- **奖杯检测**：MaixCAM 模式 2 命中码 26（绿框已确认，首帧即收）→ `CompetitionQr_GetTask2CaptureTrophy(任务码, index)` 定等级 → `TurntableInventory_RecordTrophyRank` → `Servo4_RotationSetStep`。命中后进入 400 ms 静默期防重复计数。
- 收集 3 杯 → `TrophyLittleAllClose()` → 大臂抬升到 `(1250, 2000)` → `collect_done`。
- **出口**：前八路右四路（GS5..8）全黑且抑制计数满（`MARKER_SUPPRESS_TICKS=400`，2 s）→ **ROUTE_TROPHY**（trophy_phase=0）。收集未完成时命中该标记只重置抑制计数（不退出）。
- 备注：`marker_suppress_ticks` 为负数表示"刚命中，暂时屏蔽"，用 `-(MARKER_SUPPRESS_TICKS)` 回填实现。

### 4.25 ROUTE_TROPHY（奖杯放置，phase 0~6）
| phase | 动作 |
|---|---|
| 0 | 停 100 ticks → `TrophyLittleAllClose()`、转盘锁 → phase 1 |
| 1 | 原地右转 90°（372）→ phase 2 |
| 2 | 后退 34 cm（`TROPHY_BACK_DISTANCE=62900`）→ phase 3 |
| 3~5 | `TrophyPlace_Process(task2_place_index)` 逐杯放置（子状态机见 §5），完成后 phase++ |
| 6 | 摄像头 STOP → **ROUTE_HOME_RETURN_ALIGN** |

### 4.26 ROUTE_HOME_RETURN_ALIGN（陀螺仪对准回家方向）
- 对 `home_forward_heading`（开机时记录的绝对航向）误差 ≤2° 连续 3 帧；超时 400 ticks → 直接开走。
- 对准/超时 → `ChassisPos_Start(-410700×4)`（222 cm）→ **ROUTE_HOME_RETURN_DRIVE**。

### 4.27 ROUTE_HOME_RETURN_DRIVE（倒车回家）
- `ChassisPos_Update(home_return_speed_active=400)` 完成，**或**（左位移 > 37000 且 GS5..8 全黑）→ **ROUTE_HOME_RIGHT_SHIFT**。

### 4.28 ROUTE_HOME_RIGHT_SHIFT（右移 12 cm 归位）
- `ChassisPos_Start(22200, -22200, 22200, -22200)`，`ChassisPos_Update(180, 180)` 完成 → **ROUTE_MISSION_DONE**。

### 4.29 ROUTE_PLACE_ERROR / ROUTE_MISSION_DONE
- 停车，LCD 报错 / 显示 MISSION DONE。

## 5. 子状态机：TrophyPlace_Process（奖杯放置流水线）

> 在 ROUTE_TROPHY phase 3~5 中执行，`place_index=0/1/2` 对应放置顺序（见标定清单 §7 任务映射）。每步结束 `trophy_place_settle_ticks` 清零。

```mermaid
flowchart LR
    A[PLACE_MOVE_LEFT<br/>左移3.0/3.5/3.5cm] --> B[PLACE_PREPARE_TARGET_POSE<br/>缓降手臂至align位姿]
    B --> C[PLACE_TARGET_POSE_SETTLE<br/>稳定800ms]
    C --> D[PLACE_ALIGN<br/>视觉对准 + 粗调]
    D --> E[PLACE_COARSE_MOVE] --> F[PLACE_COARSE_SETTLE] --> D
    D --> G[PLACE_FORWARD_INSERT<br/>前插4cm]
    G --> H[PLACE_INSERT_SETTLE<br/>300ms]
    H --> I[PLACE_ROTATE_SLOT<br/>转盘到目标奖杯槽]
    I --> J[PLACE_ROTATE_SETTLE<br/>800ms]
    J --> K[PLACE_LOWER_TO_RELEASE<br/>缓降release位姿]
    K --> L[PLACE_RELEASE_SETTLE<br/>1000ms]
    L --> M[PLACE_HALF_OPEN<br/>半开100ms]
    M --> N[PLACE_FULL_OPEN<br/>全开300ms]
    N --> O[PLACE_RELEASE_DETACH<br/>脱钩500ms]
    O --> P[PLACE_DROP_SETTLE<br/>落稳1000ms]
    P --> Q[PLACE_LIFT_CLEAR<br/>抬升clear位姿]
    Q --> R[PLACE_LIFT_CLEAR_SETTLE<br/>500ms]
    R --> S[PLACE_BACK_CLEAR<br/>后退5~6cm]
    S --> T[PLACE_BACK_SETTLE<br/>500ms]
    T --> U[PLACE_ROTATE_SAFE<br/>转盘回安全位]
    U --> V[PLACE_ROTATE_SAFE_SETTLE<br/>800ms]
    V --> W[PLACE_CLOSE_GRIPPER<br/>夹紧该槽]
    W --> X[PLACE_TRANSPORT_POSE<br/>抬至运输姿态]
    X --> Y[PLACE_FINISH<br/>MarkEmpty, index++]
```

关键点：
- 三套 profile（亚军/冠军/季军）分别标定 `align/release/clear` 手臂 PWM 与前插/后退距离（见标定清单 §4）。
- 视觉用 `VISION_PROFILE_TROPHY`（首杯 Start，后续 Restart）。
- 粗调（`use_coarse=1`）：视觉误差 > 47 px 时由编码器移动 `coarse_px_to_counts=27 counts/px`，限幅 1110~2775 counts。
- `PLACE_ROTATE_SLOT`：优先 `TurntableInventory_FindTrophyRank(QR 期望奖杯)`，找不到则用默认槽位。
- 放置顺序由 QR 决定：**亚军→冠军→季军**（B→A→C），杯身等级由收集顺序反推（见标定清单 §7）。
